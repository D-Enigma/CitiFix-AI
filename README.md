# CitiFix AI

AI-powered urban infrastructure monitoring and complaint management platform using Computer Vision.

## Project Structure

- `frontend/` — React frontend
- `backend/` — FastAPI backend
- `ai-model/` — YOLOv8 model development and inference
- `database/` — MongoDB database resources
- `docs/` — Project documentation
- `tests/` — Testing
- `docker/` — Docker configuration

## Tech Stack

- React + Vite
- Tailwind CSS
- FastAPI
- Python
- MongoDB
- YOLOv8
- PyTorch
- OpenCV
- Leaflet
- Docker
